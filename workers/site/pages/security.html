Security is part of the product design. No security control can eliminate all risk.

Credential storage

Direct broker and provider credentials configured in the desktop application are stored using the operating system's protected credential facilities: Windows DPAPI or macOS Keychain. The application is designed to let you replace or remove credentials without displaying their values. Do not share a device account or leave an unlocked device unattended.

Account and cloud services

Licensing and account records are stored in a Neon database accessed through Cloudflare Workers. Authentication sessions are represented server-side by token digests; database and signing keys are provisioned as Worker secrets. Access is limited by application controls and service-provider account permissions.

Planned web credential security

The web app is not available yet; these controls will be in place before web venue connections are offered. Web venue credentials for Coinbase, Kalshi and Polymarket will be stored server-side with per-user envelope encryption and will be write-only: you can replace or remove a credential but cannot view it. Desktop venue credentials stay on your device in Windows DPAPI or macOS Keychain. The hosted backend will run in a container provided by {{WEB_BACKEND_HOST}}. Per-user cloud sync for settings, strategies, watchlists and alerts is planned, and strategy-library files will be stored in Cloudflare R2.
